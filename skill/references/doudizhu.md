# 斗地主（已验证坐标）

坐标都是**渲染窗像素**，基准 1763×992。换分辨率/换游戏界面要重新标定，别硬套。
这套是 2026-10-23 深夜实战验证过的；**2026-10-24 凌晨又实战了十几局，新增第 7 节「实战硬约束」，出牌前必读那一节。**

> ⚠️ **一句话版最重要的坑**：这个游戏有「智能选牌/自动出牌」。
> 你点一张牌，它可能**自动把整副牌型选好，甚至直接替你打出去**。
> 所以：**点一下 → 马上 observe 看哪些牌抬高了 → 不要重复点同一张**（重复点＝取消选择，然后按「出牌」就会报「您选择的牌型不符合规则」）。
> 另外：**手牌会随张数变化重新排布**，每次出牌前都要重新 1:1 截图量坐标。

## 0. 进桌

- 组队房间界面：右下角橙色「进入游戏」按钮，橙色横带的中心大约在 **(1504, 895)**（实测橙色像素范围 x≈1295..1714、y≈840..952）。
- 进去后先 `mumu_observe` 确认到了牌桌，再开始。

## 1. 叫地主 / 抢地主 / 加倍（限时 2~3 秒，必须本地轮询）

按钮是左右一对：

| 含义 | 颜色 | 横带 x | y |
| --- | --- | --- | --- |
| 叫地主 / 抢地主 / 加倍×2（点它） | 橙 | 590..750 | 541 |
| 不叫 / 不抢 / 不加倍 | 蓝 | 1000..1120 | 541 |

一次调用搞定（看到左橙 + 右蓝就点左边）：

```text
mumu_wait({
  timeoutMs: 30000, intervalMs: 350,
  predicate: { type: "color", region: {x0:590, y0:520, x1:750, y1:560}, color: {preset:"orange"}, minRatio: 0.5 },
  tap: { x: 665, y: 541 }
})
```

想"不叫"就点右边蓝色带中心 (1060, 541)（先用 `mumu_observe` 的 probe 确认蓝色带在）。
脚本版逻辑（mumu-auto.ps1）还要求右蓝 `>=0.35` 才认为按钮成对出现，避免误点。

## 2. 出牌回合判定

| 画面 | 判据（橙色占比） |
| --- | --- |
| 轮到我**接牌** | 右侧「出牌」橙带 `x1160..1280, y552` ≥ 0.5 |
| 轮到我**领出** | 中间「出牌」橙带 `x900..1020, y552` ≥ 0.5 |
| 「明牌×3」提示（**不是我的回合**） | 左半边橙带 `x770..840,y552` ≥0.5 且中间 ≥0.5 且右侧 <0.5 → 忽略，继续等 |

接牌时按钮位置：不出 `x413..660`、提示 `x856..1064`、出牌 `x1116..1320`，`y 508..598`。
领出时通常中间一个「出牌」≈ (962, 553)；接牌时点右侧出牌 ≈ (1218, 553)。

等待+自动点出牌（不建议全自动，先读手牌再决定）：

```text
mumu_wait({
  timeoutMs: 120000, intervalMs: 700,
  predicate: { type: "color", region: {x0:1160, y0:508, x1:1280, y1:598}, color: {preset:"orange"}, minRatio: 0.5 }
})
```

## 3. 读手牌（mumu_scan 一次拿位置 + 选中态）

点数带：`y 640..710`，左右界 `x 250..1560`。宽 20..70px 的深色列簇 = 一张牌，
每簇 `cx` 就是这张牌的水平点按位置；牌距实测约 75~78px（17 张时）。

是否抬起（选中）：在该 `cx` 附近 `y=600` 采样平均亮度，**>200 就是选中抬起**（未选中的牌顶边在 y≈620，那里还是桌面背景）。
阈值别用 150，会误判。

```text
mumu_scan({
  region: {x0:250, y0:640, x1:1560, y1:710},
  polarity: "dark", threshold: 120, minWidth: 20, maxWidth: 70, gap: 12,
  probeY: 600, probeThreshold: 200
})
```

返回 `clusters[i] = {index, x0, x1, cx, sample, selected}`。点第 i 张牌用 `mumu_tap({x: cx, y: 680})`。

## 4. 选多张牌

- 一次点 1~2 张，然后重新 `mumu_scan` 读一遍（选中会上浮、手牌数变化会重新居中）。
- 点之前用返回的 `selected` 去重，别把已选中的再点掉。
- 点完再用 `probeY:600` 复核选中数量，和计划一致再点「出牌」。

## 5. 记牌

顶部记牌条可以直接 `mumu_observe({region:{x0:0,y0:0,x1:1763,y1:120}, maxWidth:1400})` 放大读；
牌面点数太小、字体花哨，`mumu_scan` 比 OCR 稳，别用 OCR 认手牌。
分数/局数/聊天这类文字可以 `mumu_ocr({region:{...}, scale:2})`，返回的行自带渲染窗坐标。

## 6. 界面杂项

- 「不出 / 提示 / 出牌」三按钮：先 `mumu_observe`，按上表的 x 区间直接用 `mumu_tap`。
- 结算时点屏幕中央或「继续」按钮（先 observe 确认文案位置，不同界面会变）。
- 领出单按钮时中心约 (962, 553)，但**出牌前必须先读手牌决定出什么**，不要瞎点提示。

# 7. 实战硬约束（2026-10-24 凌晨，十几局打出来的，最重要）

## 7.1 「智能选牌 / 自动出牌」——这是最大的坑

这游戏会猜你想出什么，行为有几种，**必须按下面流程走**：

1. **点 1 张牌 → 立刻 `mumu_observe` 看这 1:1 图**（见 7.2），确认哪几张「高出一截」。
   - **高出一截 = 已选中**；和它并排、明显低下去的 = 没选中。判断选中**只看高度**，别猜。
2. **不要重复点同一张**。你重复点＝取消选择。Ruic 原话：「游戏已经帮你选好了，你看旁边的牌明显低于你选的牌」「你又重复点击了，所以打不出去」。
3. 如果点 1 张后游戏**自动补齐成整套**（飞机、顺子、三带一、王炸都可能被自动补齐），**直接按「出牌」就行**，别再点。
4. 有时点 1 张就直接**自动把牌打出去**（不打「出牌」也会出）。看到手牌变了就是已经出掉了，别慌。
5. 按「出牌」报「**您选择的牌型不符合规则**」＝选中的组合不合法（常见：多选了一张相邻的牌，例如选了 9♠9♣9♦ 结果多点了一张 7；或者拿单张去应三带一）。→ 全部取消重来，先点最右那张、再往左点。

**选择顺序技巧**：抬起的牌**点击热区会往右扩张**，所以从左往右点容易一直点回同一张。
→ 需要 n 张时，**先点最右边那张，再依次往左点**；或者点完一张就先 observe 确认，再按新布局点下一张。

## 7.2 每手牌都要重新 1:1 截图

**手牌张数一变，整排位置全变**（游戏会把牌重新居中/重排）。Ruic 原话：「你以后实时捕获游戏画面因为你牌少了坐标会变」。
所以**每次要选牌前**：`mumu_observe({region:{x0:0,x1:1763,y0:500,y1:900}, maxWidth:1763})`，1:1 看清每张牌的实际位置再点。**不要复用上一手的坐标。**

实测布局参考（基准 1763×992，点击行 y≈760～780 最稳）：

| 手牌张数 | 起点 x | 牌距 |
|---|---|---|
| 20 张 | ≈240 | ≈78 |
| 17 张 | ≈250 | ≈75 |
| 13 张 | ≈310 | ≈83 |

选中后整张牌抬高约 **30～40px**；`y≈690` 有时点不中，`y≈760～780` 稳。

| 出牌（橙） | (1210, 546) | 有「不出/提示」时的第三个按钮 |
| 要不起（蓝） | (955, 547) | 场上牌太大压不住时，只有一个按钮 |
| 出牌（领出时） | (960, 545) / (1094, 545) | 领出时没有「提示」，只有「明牌+出牌」 |
| 叫地主（橙） | (661, 546) | 抢地主 / 加倍×2 也在同一位置 |
| 不叫 / 不抢 / 不加倍（蓝） | (1087, 546) | |
| 结算「继续游戏」 | (1450, 830) | |

**「明牌×2 / 明牌×4」千万别点**（会把我的牌亮给对手看，实战里吃过大亏）。
**「明牌开始×5」也别点**。开新一局时那个橙色大字按钮叫「开始游戏」，跟「明牌」是两回事。

## 7.4 节奏

- 叫地主/抢地主/加倍只有 8～14 秒倒计时，**30 秒内必须做出决定**（Ruic 要求）。
- 机器人经常很慢（30～60 秒思考），用 `mumu_wait({predicate:{type:"color", color:{preset:"orange"}, region:{x0:880,y0:510,x1:1060,y1:600}, minRatio:0.3}})` 等「出牌」按钮亮起＝轮到我，比反复截图省事。
- 注意 `mumu_wait` 里把计时徽标区域排除掉，否则倒计时数字变化会一直触发 diff。

## 7.5 卡住 / 弹窗

- 结算后「继续游戏」点了没反应、或出现「队长提醒您点击准备/开始游戏」：多半是**房主暂离/房间失效**。回大厅（左上返回键）→ 重新进好友房，**分数保留**。别一直点，点不动的。
- 游戏内弹窗（如「无限补给」广告）**点右上角 ×** 即可，找不到就等几秒它会自动关。
- `mumu_*` 调用偶尔返回「调用已取消（已重启 MuMu worker）」——worker 重启了，重新 `mumu_observe` 继续就行。
- **别用 `mumu_shell` 的 `input tap`**：那是 display 0（桌面），游戏在 display 3，会把画面切到桌面。要用 `mumu_tap`。

## 7.6 打法（打出来的心得）

- **农民：别压队友的牌**；队友牌少就让他走（农民任一人走完都算农民赢）。配合思路：自己用炸弹抢回出牌权后，**喂一张小单牌**给只剩 1 张的队友，他压过去就赢（这一手实战翻过盘）。
- **地主：先甩小牌/三带二，炸弹留到最后收**。手里双王/大炸弹时注意倍数会滚很大（炸弹×2），牌不够硬别把倍数炸上去。
- **明牌后对手会算你的牌**，尽量不点明牌。
- 出完最后一张牌立刻判胜，所以"手牌只剩炸弹"时是最稳的收尾形态。
- 结算分数有封顶（见过 ±512 封顶）。

# 8. 第二晚实战补充（2026-10-24 凌晨续，6 局 1 胜、累计 −320）

> 一句话：**这一晚不是输在牌，是输在倍数**。−320 里一大半是"倍已经 8/16 还去加倍，对手再放炸弹翻倍"造成的。
> 拿到牌之前，先读 8.1（倍数纪律）和 8.2（记牌）。

## 8.1 倍数纪律（最贵的一课）

- **倍 ≥8 之后不再主动点「加倍×2」**。牌再硬也先算一句"这一局输了能不能接受"。
- **对手每一个炸弹都会把倍翻倍**。实测一条链：2（叫地主）→4（我加倍）→8（我 6666）→16（对手 3333）→32（我又 JJJJ）→64（收尾）。倍一滚起来，一局就是 ±64 / ±128。
- 炸弹的正确定位是**抢出牌权 / 收尾**，不是"为了赢更多分"。手里有双炸弹 ≠ 该炸。
- 反例（我）：第 4 局 AAA、222 全打光，对面 KKKK 一直没露面，一局 −128。

## 8.2 记牌（开局就记，别等落后再算）

- 每出一手记一笔；出牌前问两句：**外面这一档还剩几张？谁可能握着什么？**
- 倒推法：54 − 我手里的 − 桌面上出过的 = 别人手里的。重点盯 **2 / A / K / 王**，以及"四张齐了没有"（炸弹）。
- 实例：第 5 局我自己有三张 2 三张 A → 外面各只剩单张，所以 22 对子无敌；第 6 局算出外面可能还有大小王——最后就是王把我压死的。
- 记牌直接决定两件事：**该不该抢**、**该不该留**。前 4 局全凭感觉，第 5 局开始算，已经落后 −192。

## 8.3 「智能选牌」会把你选的牌**升级成大牌型**

- 实例：我选 **QQQ + 77**（想打三带二，5 张），游戏自动补成**飞机 QQQJJJ + 77**，**实际出了 8 张**（手牌 20→12）。我按 5 张算，后面的计划全错。
- 所以：选完必须**数一遍抬起的牌数**再按「出牌」，别只盯着"我点的那几张"。
- 反过来也能用：想打飞机/飞机带翅膀时，点一组三张让它自动补齐即可。

## 8.4 「您选择的牌型不符合规则」两种原因

1. 真选错了（多选/少选/牌型不匹配）；
2. **选择状态没提交**：选好马上点「出牌」偶发这个报错——**重新选一次再点就过了**（这一晚遇到 2 次）。
- 处理顺序：observe 看抬起的牌对不对 → 不对就逐个点到对 → 再「出牌」；还报错就全取消重选。

## 8.5 分清桌面上的「当前手」和「上一手」

- 三家出的牌会同时留在桌面上各占一块，最容易误判的是"我看到的这两张 44 是上一手还是当前手"。
- 判断法：看**对手剩余牌数**（头像旁 17→11 = 他这手出了 6 张，那就是四带二，不是对子）；再结合 `mumu_wait` 直到「出牌」按钮出现前最后一帧。
- 踩过的坑：`444+88`（三带二，5 张）和 `4444+2+7`（四带二，6 张）看混。

## 8.6 互动工具（Ruic 教我的，允许"大优势时按自己喜欢的用"）

入口：右下角「聊天」**(1695, 941)** → 右侧面板，竖标签 **快捷 / 表情 / 动作**。

- **快捷语**（点一行直接发，我的头像边冒气泡）实测 10 句：
  `心态崩了呀 / 就这？ / 我要验牌 / 十七张牌，你能秒我？！（带「经典」标）/ 这谁顶得住啊 / 顶不住也要顶 / 我能怎么办，我也很绝望啊 / 快点啊，等到花儿都谢了 / 你的牌打得也太好了 / 你是MM还是GG`
  行距约 72px，第一行 y≈160，点 x≈1408。
- **表情**：顶部是对方名片（欢乐豆 / 删好友 / **👍点赞**（点一次 +1）/ 牌友印象徽章：给力队友·实力选手·最美穿搭·种田大师·成就达人）；
  中间 **免费表情 5 个**（渲染窗像素，y≈382）：🪣`(1038,382)` 🐔`(1200,382)` 🐝`(1363,382)` 🍵`(1526,382)` 🍅`(1685,382)`——点一下直接丢到对手身上播动画（番茄砸脸）；
  下面「高级」是付费表情（30💎/15💎）。
- **动作**页尚未实测（下次补）。
- 规则（Ruic 原话意思）：**互动不用等我的回合**，因为模拟器是窗口运行的；**别人朝我丢东西，我可以自己选择回不回**。"大优势的时候可以根据你喜欢的用"，逆风别嘴。

## 8.7 对局流程 / 结算

- 好友房一轮默认 **6 局**。每局结算点「继续游戏」**(1451, 833)** → 回房间点「开始游戏」**(870, 560)**。
- 第 6 局打完出的是「好友同玩战绩」榜（本轮结束），按钮变成 **「再来一轮」**（积分清零重算）/「分享战绩」，不再是「继续游戏」。
- 榜单口径：「对局 6 / 胜局 N / 累计分」。这一晚：汐眠秂 +160、右座 YanAnt1 +160、我 −320。
- 房间信息：好友房 **962376**、不洗牌、底分 1、**不结算欢乐豆**（打的是房内积分，没有豆子风险）。

## 8.8 两个容易误判的显示

- **回合倒计时是 300 秒级的**（见过 258/210/189/298…），不是 3 秒，别被数字吓到乱点；真正短的是**叫地主 8～14 秒**。
- 「明牌 ×2 / ×4 / ×3」任何时候都别点（会把牌亮给对手）。
